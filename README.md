# Machine Learning – Semester 5

A collection of Machine Learning experiments and practical implementations completed as part of the Semester 5 curriculum. This repository contains Python-based Jupyter Notebooks covering fundamental ML algorithms, data analysis techniques, dimensionality reduction, clustering, and classification.

## About

This repository serves as a collection of hands-on Machine Learning experiments designed to understand and implement different ML algorithms using Python.

It covers various supervised and unsupervised learning techniques, along with data preprocessing, exploratory data analysis, and feature extraction methods.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Python 3.x
- Jupyter Notebook or JupyterLab
- Required Python libraries

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Rishi-Sampat/ML.git
```

**2. Navigate to the project directory**

```bash
cd ML
```

**3. Install the required libraries**

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

**4. Launch Jupyter Notebook**

```bash
jupyter notebook
```

**5. Open any `.ipynb` file** and execute the cells to explore the corresponding experiment.

Alternatively, the notebooks can be opened using Google Colab.
